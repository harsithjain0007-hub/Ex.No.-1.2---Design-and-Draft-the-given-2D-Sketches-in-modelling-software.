# Ex.No.-1.2-Design and Draft the given 2D Sketches in modelling software.
## DATE:20/11/2026
## REF NO: 26014758

## AIM
 To sketch the given drawing with dimensions using fusion 360 tool.
 
## REQUIREMENTS
 1. Autodesk fusion 360
 2. Windows 10
 3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
 4. 2.5 Mbps or faster download; 500 Kbps or faster upload 
 
## PROCEDURE
## Step 1: Start a New Sketch
Create a new design, set the units to mm, and start a sketch on the XY plane. Use the origin as the center of the part.

## Step 2: Draw the Concentric Circles
At the origin, draw three concentric circles with diameters Ø30 mm, Ø42 mm, and Ø60 mm. These form the center opening and the inner and outer boundaries of the central ring.
<img width="1658" height="1311" alt="Screenshot 2026-11-27 090816" src="https://github.com/user-attachments/assets/72d86cc7-7053-4007-b579-e1c7fcb620e0" />

 
## Step 3: Sketch One Radial Section
At the top of the ring, sketch one narrow spoke and its adjoining outer section. Set the spoke width to 6 mm and align the section with the vertical centerline.
<img width="1005" height="884" alt="Screenshot 2026-11-27 092312" src="https://github.com/user-attachments/assets/c196161f-4498-490e-b22a-65a0fe9a96ef" />


## Step 4: Circular-Pattern the Section
Choose Sketch → Circular Pattern. Select the spoke and adjoining section, set the pattern center to the origin, and create 6 instances over 360°.
<img width="1410" height="1314" alt="Screenshot 2026-11-27 090921" src="https://github.com/user-attachments/assets/8f496084-2a04-4387-bbe8-2dc9fe6981c7" />


## Step 5: Draw the Outer Circular Pads
draw a lie above both x and y axis for mirroring.choose one side and sketch two outer pads including half outer circle.

## mirroring with respect to x axis :
select the sketch to mirror and select the mirror axis as X and press enter
